# Carpeta de Facturas de Entrada

Coloca aquí los archivos PDF de facturas de **Gases del Caribe S.A. E.S.P.** (1 página por archivo `.pdf`, por ejemplo `factura_01.pdf`, `factura_02.pdf`, etc.).

Puedes agregar, quitar o reemplazar archivos en cualquier momento y presionar **"Refrescar carpeta"** en la interfaz web para detectarlos al instante.
